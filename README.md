# website3

Dan Hu's single-page portfolio. It is an original, static Vite site inspired by the editorial composition of Peter Wu's portfolio, using Dan's existing bio, résumé, headshot, and project assets.

## Develop locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

The production output is written to `dist/` and can be deployed to Vercel, Netlify, or GitHub Pages.
